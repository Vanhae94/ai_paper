8월의 AI — 에이전트가 '실행 골격(하니스)'의 문제로 재정의되고, 신뢰(보안·검증)가 의제가 되며, 프런티어가 개인 기계로 내려온 한 달

이달의 사건 — BDH-CQ, 3주 연속 최고 경신 부상

8월 후반 트렌딩을 지배한 것은 BDH-CQ였다. 642(W34) -> 710(W35) -> 765(W36)로 3주 연속 관측 이래 최고치를 갈아치웠고, 직전 기록이던 Kimi K3의 486을 크게 넘어섰다. 150M 파라미터로 중간 추론을 언어화하지 않고 고차원 잠재 공간에서 순환 연산으로 ARC-AGI-1을 푸는 접근이, 거대 모델과 장문 사고사슬이라는 주류와 정반대라서 더 화제가 됐다. 학습 포인트: 아이디어의 가치는 크지만 심층 분석 결과 '파레토 돌파' 주장에는 세 겹의 한정이 붙는다 — 자기 점수는 pass@2 29.5%(pass@1은 24.25%), 비용은 자사 GPU 원가($3/H200-시간)와 상업 API 정가의 비교, 그리고 저자 스스로 API 가격 인하 반영 시 57배 우위가 11배로 줄어든다고 적었다. 인용할 때는 '정확도 SOTA'가 아니라 '비용 효율 축의 주장'으로 옮기는 것이 정확하다.

8월의 핵심 — 에이전트가 '모델 문제'에서 '하니스 문제'로 옮겨가다 지속

8월 내내 가장 두꺼웠던 흐름은 에이전트의 실행 골격과 상태 관리다(누적 agentic-workflow 26회, 12주 전부 등장). 5주에 걸쳐 조각이 하나씩 채워졌다 — W33 LongHorizon-Harness는 장기 실행을 '작업 상태 관리 문제'로 재정의해 상태를 컨텍스트 밖에 두고 환경으로 검증된 사실만 반영하는 MEA(Manage-Execute-Audit) 루프로 Qwen 3.7-Plus의 WeaveBench를 51.8%에서 80.7%로 올렸고, W34 COLLEAGUE.SKILL은 사람의 흔적에서 검사·수정 가능한 스킬 패키지를 증류했으며, W36에는 Prime Agent(실행·복구·검증·자원회계를 표준화하고 전략은 모델에 맡김)와 Apodex 1.1(Environment Scaling + Agentic Coordination Scaling, AgentOS의 상태·출처 관리)이 나란히 올랐다. 공통 문제의식은 하나다: 모델 능력과 별개로 실행 골격이 성능을 좌우하며, 하니스가 부실하면 모델의 진짜 능력이 아니라 하니스의 한계가 측정된다. 학습 포인트: 에이전트를 개선하려 할 때 모델 교체보다 상태 외부화·검증 분리·컨텍스트 리셋 같은 골격 설계가 더 큰 폭의 개선을 낼 수 있다.

신뢰가 의제로 — 보안과 검증이 처음 등장 부상

W35에 이 시스템 관측 이래 처음으로 Safety와 Evaluation이 1차 카테고리로 나란히 올랐다. AI-Infra-Guard는 에이전트 공격면을 인프라·프로토콜/도구·에이전트 행동·모델 4층으로 나누고 층마다 다른 탐지 패러다임(규칙 매칭 75개 구성요소·1,400개 규칙, MCP와 스킬 패키지에 대한 LLM 에이전틱 감사, 다중 턴 블랙박스 레드티밍, 탈옥 하니스)을 붙였고, 특히 에이전트를 확장하는 '스킬'의 공급망 감사를 포함한다. LLM-as-a-Verifier는 채점 토큰 로짓의 기대값으로 연속 점수를 만들어 검증 자체를 새 스케일링 축으로 제시했다. 학습 포인트: 에이전트가 실무에 들어가면서 '되는가'에서 '믿을 수 있는가'로 질문이 옮겨간다. 스킬과 MCP를 직접 만들어 쓰는 입장이라면 공급망 감사 관점은 남의 얘기가 아니다.

프런티어가 개인 기계로 — 공개 가중치와 로컬 실행 지속

8월은 프런티어급 공개 가중치가 쏟아진 달이자, 그것을 내 기계에서 돌리려는 시도가 함께 뜬 달이다. W32 Kimi K3는 2.78T 총 파라미터·104B 활성·1M 컨텍스트를 전면 공개했고(다만 자체 Kimi K3 License로 MaaS 매출 조건이 붙어 'Open Frontier'라는 제목보다 개방 범위는 좁다), W35~W36의 FreeToken은 개인 PC를 '작은 GPU'가 아니라 탄력적 추론 플랫폼으로 재해석해 노트북 35B, 게이밍 데스크톱 284B, 워크스테이션 GPU 1장에 753B GLM-5.2까지 올렸다. FreeToken의 스타가 2주 만에 3.2k에서 10.6k로 뛴 것이 수요의 크기를 보여준다. 학습 포인트: 효율화의 방향이 7월의 '모델을 작게'에서 8월엔 '큰 모델을 가진 자원에 맞게 재배치'로 이동했다. KV캐시·전문가 상주·CPU-GPU 분할 같은 서빙 계층 지식의 실용 가치가 커졌다.

생성 모달리티의 동시다발 확산 지속

7월이 문서 -> 월드모델 -> 오디오 -> 이미지로 바통을 넘기는 릴레이였다면, 8월은 여러 모달리티가 한꺼번에 올라온 달이다. W32 한 주에만 비디오 생성(LongCat-Video), 3D 생성(TRELLIS.2의 O-Voxel, 기하와 PBR 재질을 한 희소 복셀에 통합해 16배 압축), 음성 합성(VibeVoice, Encodec 대비 80배 압축으로 90분 4화자)이 동시에 올랐고, W33 실시간 비디오 편집(JoyAI-Video-Edit, 720p 30FPS), W35 단안 영상 4D 인체 복원(4DAnyone), W36 멀티모달 임베딩(WeMM)으로 이어졌다. 공통점은 품질 경쟁을 넘어 실시간성·효율·표현으로 축이 옮겨간 것이다. 한편 6~7월 강세였던 문서 파싱은 Unlimited OCR이 4주 연속 등장한 뒤 8월 마지막 두 주에는 빠졌다. 학습 포인트: 모달리티마다 따라가기보다 공통 레시피(전용 토크나이저, 소수 스텝 증류, 문맥·캐시 압축)를 횡단으로 익히는 편이 효율적이다.

이달의 메타 교훈 — 헤드라인 수치와 각주 조건의 거리

8월에 12편을 심층 분석하며 반복적으로 확인된 패턴이 있다. 헤드라인 수치는 대개 사실이지만, 그 수치가 성립하는 조건이 각주와 표 캡션에 있다는 것이다. BDH-CQ의 29.5%는 pass@2였고(pass@1은 24.25%), Apodex 1.1의 '선두 성능대'는 표 캡션이 밝히듯 선택된 비교행 안에서의 주장이며 공개 벤치에서는 GDPVal 78.8 대 89.4, SWE-bench Verified 77.7 대 92.2로 뒤진다. WeMM-Embedding의 '2B가 기존 8B를 능가'는 Video 서브셋이 만든 결과로 Image에서는 낮고, Prime Agent는 nanoGPT 스피드런에서 '하니스 선택이 최종 기록에 거의 영향이 없다'는 널 결과를 스스로 보고한다. LLM-as-a-Verifier는 oracle 상한(Terminal-Bench V2 Pass@5 92.1%)을 함께 봐야 검증기의 실제 위치가 보인다. 학습 포인트: 표를 읽기 전 세 가지를 먼저 확인하는 습관을 들이자 — (1) 베이스라인이 원 보고치인가 저자가 자기 하니스에서 재현한 값인가, (2) 행마다 실행 환경(하니스·모델)이 같은가, (3) 실행 횟수와 분산이 보고되는가. 이 셋만 확인해도 8월의 여러 표를 오독하지 않는다.
